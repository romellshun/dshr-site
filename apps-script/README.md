# Приём результатов теста в Google Таблицу

Тест на сайте отправляет результат в веб-приложение Google Apps Script, а оно добавляет строку в Google Таблицу. Всё работает бесплатно и не требует сервера.

## 1. Создайте Google Таблицу

1. Откройте [Google Таблицы](https://sheets.new) под своим Google-аккаунтом.
2. Назовите файл, например `ДШР — результаты теста`.
3. Создавать листы и заголовки вручную не нужно: скрипт сделает лист `Результаты` и шапку сам.

## 2. Откройте редактор Apps Script

1. В таблице выберите **Расширения → Apps Script**.
2. Удалите код-заглушку в файле `Код.gs`.
3. Вставьте всё содержимое файла [`results.gs`](results.gs).
4. Нажмите **Сохранить** (Ctrl+S) и дайте проекту имя, например `ДШР — результаты теста`.

Если редактор открыт не из таблицы, а отдельно, впишите ID таблицы в переменную `SPREADSHEET_ID` в начале скрипта. ID — это часть ссылки между `/d/` и `/edit`.

## 3. Разверните веб-приложение

1. Нажмите **Развернуть → Новое развёртывание**.
2. Тип — **Веб-приложение**.
3. Параметры:
   - **Описание**: `Приём результатов теста ДШР`
   - **Выполнять от имени**: `Я`
   - **У кого есть доступ**: `Все` (Anyone)
4. Нажмите **Развернуть**.
5. Google попросит авторизовать доступ — разрешите его для своего аккаунта.
6. Скопируйте **URL веб-приложения**. Он заканчивается на `/exec`, например:

```text
https://script.google.com/macros/s/AKfycb.../exec
```

> Важно: нужен именно URL вида `/exec`, а не `/dev`. Ссылка `/dev` работает только под вашим аккаунтом.

## 4. Подключите URL к тесту

Откройте `assets/js/test.js` и найдите в начале файла:

```js
const CONFIG = {
  endpoint: '',
  ...
```

Вставьте URL в `endpoint`:

```js
endpoint: 'https://script.google.com/macros/s/ВАШ_ID/exec',
```

Либо просто пришлите URL — его впишут и опубликуют сайт.

После изменения версии файлов на сайте поднимите `?v=` у CSS и JS в `index.html`, чтобы браузеры не взяли старую версию из кэша.

## 5. Проверьте отправку

1. Откройте тест: `#/test`.
2. Заполните никнейм, статик-ID и подразделение.
3. Пройдите тест до конца.
4. В Google Таблице на листе `Результаты` должна появиться новая строка.

Если строка не появилась:

- убедитесь, что развёртывание сделано с доступом **Все**;
- проверьте, что используется URL `/exec`;
- после правок скрипта нужно выпустить новую версию: **Развернуть → Управление развёртываниями → карандаш → Версия: Новая версия → Развернуть**. URL при этом не меняется;
- откройте журнал выполнения в Apps Script (**Выполнения**) — там будет текст ошибки.

## Что записывается в таблицу

| Колонка | Содержание |
| --- | --- |
| ID результата | Уникальный ID попытки, защищает от дублей |
| Дата отправки | Когда пришёл результат |
| Никнейм, Статик-ID, Подразделение | Данные кандидата |
| Баллы, Всего, Процент | Результат теста |
| Статус | `СДАНО` или `НЕ СДАНО` |
| Время, сек | Сколько длился тест |
| Автозавершение | Как завершился тест: `нет`, `да (вкладка)`, `да (вопрос)` или `да (время)` |
| Начало, Завершение | Время начала и окончания |
| СВУ, Первая помощь, Переговоры, Штурм, Запреты главы 4 | Баллы по темам |
| Ошибки (JSON) | Вопросы, где кандидат ошибся |
| Все ответы (JSON) | Полный разбор ответов |

## Правила прохождения

- На каждый вопрос даётся **1 минута 10 секунд** (70 секунд). Когда время вопроса истекает, сайт сам переходит к следующему вопросу; если это был последний вопрос — завершает тест.
- Ответ фиксируется сразу после выбора: изменить его нельзя.
- Возврат к пройденным вопросам и переходы по разделам сайта во время теста запрещены. Навигация работает только вперёд.
- Переключение вкладки, сворачивание окна или переход в другое приложение автоматически завершает тест. Результат при этом отправляется, а в колонке `Автозавершение` будет `да (вкладка)`.
- Общий лимит — 35 минут. Когда он истекает, тест завершается автоматически (`да (время)`).
- В тесте 30 вопросов, которые выбираются случайно из общего банка (50 вопросов) и полностью перемешиваются. Для прохождения нужно ответить правильно на 25 из 30 (83%).

## Ограничение повторных попыток

Кандидат может пройти тест **один раз**. Любая завершённая попытка — и сданная, и несданная — закрывает повтор. Вторая попытка открывается только командиром.

Кандидат определяется по **статик-ID** (без учёта регистра и лишних пробелов). Никнейм используется только для отображения в таблице: смена никнейма не открывает новую попытку.

### Как разрешить повтор

1. Откройте лист `Результаты` (или `Разрешения`).
2. Кликните на строку кандидата.
3. В меню таблицы выберите **ДШР → Разрешить повтор (выбранная строка)**.
4. Подтвердите. В листе `Разрешения` появится строка со статусом `Разрешено`.

Можно и без выбора строки: **ДШР → Разрешить повтор (ввести вручную)…** — введите статик-ID и никнейм.

После того как кандидат воспользуется разрешением и результат запишется, статус автоматически сменится на `Использовано`. Разрешение действует ровно на одну попытку.

### Как отозвать разрешение

Выберите строку кандидата и выберите **ДШР → Отозвать разрешение (выбранная строка)**. Статус сменится на `Отозвано`, и повтор снова будет закрыт.

### Лист «Разрешения»

| Колонка | Содержание |
| --- | --- |
| Статик-ID | Статик-ID кандидата |
| Никнейм | Никнейм кандидата |
| Статус | `Разрешено`, `Использовано` или `Отозвано` |
| Выдано | Когда выдано разрешение |
| Комментарий | Служебная пометка |
| ID результата | Какой результат закрыл разрешение |
| Дата использования | Когда разрешение израсходовано |

> После правки `results.gs` обязательно выпустите новую версию развёртывания: **Развернуть → Управление развёртываниями → карандаш → Версия: Новая версия → Развернуть**. URL не меняется.

## Безопасность и ограничения

- Ссылка веб-приложения публичная: любой, кто её знает, может отправить POST. Для аттестации это приемлемо, но не публикуйте URL без необходимости.
- Повторная отправка с тем же `ID результата` не создаёт вторую строку.
- Ограничение попыток рассчитано на честных кандидатов: при желании статик-ID можно подделать. Полностью защититься на статическом сайте нельзя.
- Если сайт не может проверить попытки (нет связи или развёрнута старая версия скрипта), старт теста блокируется. Это защищает от повторного прохождения, но требует, чтобы скрипт был развёрнут.
- Скрипт не хранит ничего, кроме данных, которые присылает тест, и выданных командиром разрешений.
- Если кандидат закроет вкладку, черновик ответов сохранится в его браузере, но таймер продолжит идти. При возврате тест автоматически завершится как прерванный, если вкладка была скрыта или окно потеряло фокус.
